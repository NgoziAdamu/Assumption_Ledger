2. 新 a 规则按真实 shell 命令结构静态识别：重定向写入的字面路径，与后续 `python`、`python3`、`bash`、`sh` 的脚本参数完全相同，且写入语句在运行语句之前。heredoc 正文先按原边界隔离，避免把正文里提到的运行命令当作实际运行。共 **68 个动作**命中新增写后运行情形，其中 **65 个动作**此前没有 a 标签，a 总计从 97 增至 162；另外 3 个动作已有其他 a 子条件。只保存而不在同一命令运行的脚本不因此加 a，以后运行仍按旧 b。

账本 JSON 文件必须是数组；每项含 `id`、`call`（也接受字段名 `第几次叫起`），以及做法一输出的八个字段 `statement/about/target/evidence_of_dependence/alternative/importance/reason/updates`。不生成、过滤、合并或重排条目，所有额外字段和值也保留；填充为 `ensure_ascii=False, indent=2` 的 JSON 文本。文件缺省或数组为空填 `(none)`，`null` 和对象被拒绝。`--ledger-file` 是 `--ledger-json` 的同义参数。模板只填充一次，轨迹/账本原文中的大括号不会被二次替换。

每题 calls 的编号包括末尾 f；若给出的数字指向 f，接口提示改用 `--final-rank`。交卷重排可用空账本拼装占位文本，但统计遵用户要求只记次数，不计算或外推最终重排 token。拼装读取哈希核验后的轨迹、原契约和 031 文档引用，不执行 agent 命令，不打开数据库或 CSV/Excel 数据文件，不提供裁判拼装入口。
