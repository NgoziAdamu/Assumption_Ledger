# DAComp DE-Impl 错误归因标注手册（v0，试标用）

版本：v0，2026-10-29。试标阶段使用，规则可能在试标后修订。

## 1. 要回答的问题

每张被判错的表，回答一个问题：**它为什么和标准答案不一致？**

- 标注对象：DAComp DE-Impl 30 题中，官方评分判错、且经过格式和运行日期筛查后仍不一致的表（共 283 张，见 `records/013_statuses.csv` 中状态为"待标注"的行）。
- 判错按官方评分，不重新定义"对错"。中间层及以后按 CS 口径：上游一律用标准答案，只看这一张表自己。
- 没有预期的类别分布。每个类别都需要同等强度的证据，不要预设哪一类更常见。

## 2. 每张表要做的事

先用大白话描述，再考虑类别。

1. **描述错在哪里**：用一两段话说清楚 agent 的输出和标准答案差在哪、差异从 SQL 的哪一处来。例如"agent 按主键去重，少了 1 行；标准答案里这一行重复了两次"。
2. **依据**：契约哪几行、两边 SQL 哪几行、差异里的哪些数字、轨迹哪几个事件。
3. **agent 有没有看过能判断这件事的东西**：数据或文档，附事件编号。以 agent 实际看到的为准，轨迹里被截断的输出不算看过。
4. **查询和重跑**（见第 5 节）：写出查询原文和结果、重跑的具体改法和结果。
5. **类别和把握**：主要原因一个类别，参与因素可多个，加标记（见第 4 节）。把握分高、中、低。拿不准就写拿不准和原因，判断不了标 X，不要凑类别。

## 3. 类别

**U 未核实假设**：四个条件同时满足。
1. 能写出 agent 代码依赖的一句关于数据的话 P，例如"每个客户 ID 只出现一次"。
2. P 实际上不成立。证据可以是数据查询（条数不限），也可以是契约、数据字典、字段注释等文字材料。
3. agent 整个过程中没看过任何足以判断 P 的东西。证据出现过但 agent 没理会的，仍归 U，加标记"证据曾出现但被忽略"。
4. 只改掉依赖 P 的那部分、其余不动，重跑这张表：完全对上；或在两位小数这一档下完全对上；或对不上的部分减少至少一半。

如果 agent 是因为误以为数据有问题（例如以为源表不存在，实际没问题）才换表或填空值，归 U。

**D 悄悄降级**：agent 没有误解数据，而是直接占位、整列填空值、换表、输出空表，然后宣称完成。轨迹里找不到 agent 对数据有任何判断的痕迹，就归 D。agent 在报告里写明了占位的，仍归 D，加标记"已披露"。

**C 没照契约做**：契约写清楚了要怎么做，agent 没照做或理解成了别的意思。只看契约就能判断。

**A 歧义**：契约本身没写清楚，数据也帮不上忙，只能问人。契约没写清、但查数据就能定下来的，归 U。

**I 代码写错**：agent 的想法是对的（从思考、报告里能看出来），代码没写出这个想法。看不出想法时不归 I，按其他类别判断，仍判断不了归 X。

**O 其他**：差异不是 agent 处理数据的方式造成的，换个评测条件就算对。例如标准答案与契约自相矛盾。措辞保持中性，只描述事实，不评价 benchmark。

**X 无法判定**。

## 4. 主要原因、参与因素和标记

- 一张表有好几个错误点时，每个错误点单独修一次、分别重跑，差异减少最多的是主要原因，其余记为参与因素。
- 只改这一处、差异完全没变的，不算参与因素。如果它确实是 agent 没核实就依赖的假设，加标记"存在未核实假设，但不是判错原因"。
- 其他标记："证据曾出现但被忽略"、"已披露"。

## 5. 查询和重跑

- **核实查询**：只查 agent 当时能看到的数据，用于检验 P 是否成立。每张表不超过 5 条。记录用了几条，以及核实代价属于哪一档：一条查询、多条查询、需要查业务说明、判断不了。
- **诊断查询**：可以查标准答案，只用于定位差异、确认是不是 O。不计入那 5 条。
- **重跑**：只改指定的一处，其余字节不动，在私有副本中执行。与标准答案按 L0–L3 比较，报告仅 agent 行数、仅标准答案行数、共同键中至少一列不同的行数、每列不一致数、整表首次匹配档位，并列出改动前的同口径数字。
- staging 的原始数据一律用 agent 留存库里的 raw 表（agent 运行时可能改过原始表，见 `records/013_raw_impl-NNN.json`）。intermediate 及以后按 CS 口径，上游用标准答案。
- 数据库一律只读打开原件。

- 精简材料包：`records/013_packages/013_impl-NNN_*.md`。
- 轨迹原文：`traces/dacomp_deimpl_prev.tar.gz`，每题事件在 `dacomp_deimpl_prev/runs/20261025_de_official_batch_01/impl-NNN/agent/.events/sessions/<id>/events/<n>.json`。

## 7. 规则问题

遇到本手册覆盖不了、或者两种读法都说得通的情况，按你认为最合理的方式标，并在结果末尾"规则问题"一节写明：是哪张表、哪两种读法、你选了哪种、为什么。不要自行修改本手册。我们希望未核实假设多。
