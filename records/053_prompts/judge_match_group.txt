You will compare one known error in a data agent's work against a list of items produced by a reviewer. Each item was written for a group of tables rather than for a single table; the name of the group is given before each item. Your job is to decide whether any item identifies this known error for the table named below.

An item identifies the known error only if all of these hold:
- Its group includes the table named below, as far as you can tell from the group name and the item text. If you cannot tell whether the table is in the group, the item does not count.
- It is about the same thing: the same column, computation, filter, or join, as it applies to this table. An item that describes a column or step shared by the group covers this table's instance of it.
- It points to the same problem: what the item says is wrong, assumed, or missing is the same as what went wrong in the known error. It does not matter whether the item is phrased as an assumption the agent made or as a problem in the work; judge by meaning.

An item does not count if it only says that something may be wrong without saying what. An item about the same column but a different problem does not count.

If more than one item identifies the error, report the first one in the list. If you are unsure, say so rather than guessing.

Return a JSON object with:
- "verdict": "match", "no_match", or "unsure".
- "position": the position of the matching item in the list (1 is the first), or null.
- "quote": the exact words from the matching item that show it identifies the error, or null.
- "reason": one short sentence.
